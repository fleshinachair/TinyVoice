# Mode roster and source layout

Note: `docs/humanoid-plan.md`, mentioned in the Layout table, lives in the calibration lab repo (`C:/Github/TinyVoice-lab`), not here.

| # | Mode | Engine | What it is |
|---|---|---|---|
| 0 | Robot | `daft.c` | 16-band vocoder, 4-voice MIDI carrier, drone fallback, formant shift, odd/even stereo, VP-330 ensemble |
| 1 | Snap | PSOLA lead (`modes.c`) | Hard "space-age" Auto-Tune: formant +2.5 st, telephone band with a 2.5 kHz bite; instant at Beauty 0 |
| 2 | Chords | `imogen.c` | 4-voice harmonizer, formant-preserving PSOLA voices, pad-rooted or scale chords (strictly triadic: root, 3rd, 5th, octave) |
| 3 | Prism | 4 PSOLA voices + glass (`modes.c`, `ssb.h`) | 0 ms snap split into 4 harmony lines + tape warmth, then **refraction**: off-grid voice offsets, a Hilbert-shifted L/R pair (non-integer partials) and a modulated comb. Refract (char4) 0 = exactly the old Prism |
| 4 | Tape | delay-line tap (`modes.c`) | Varispeed drop with wow/flutter, dark top, saturation; char4 aliases Tone, char5 = Hiss (tape hiss above 0.5) |
| 5 | Nightcall | `daft.c` (second instance, `daft_set_talker`) | DigiTech-Talker style talkbox: 12-28 % pulse carrier + ~10 % white noise, 250 Hz 4th-order low-cut, 1.2 kHz cavity peak, high shelf, 17.5 % unvoiced breath bleed; pads or drone carry |
| 6 | Scream | PSOLA lead (`modes.c`) | The prank-caller voice changer: -8 st, formant x0.84 (a big throat), a wide band (90 Hz-4.8 kHz) that keeps the chest, clean until Grit is raised; Narrow closes it into a phone line |
| 7 | Dalek | `voice.c` + `ssb.h` | Hilbert-pair single-sideband shifter (+-500 Hz) + 30 Hz ring mod + comb "metal" |
| 8 | HardTune | PSOLA lead (`modes.c`) | Zero-slew quantizer (Key/Scale or a pad), formant preserved, correction depth 0-200 % |
| 9 | Harmony | `voice.c` | 3-tap granular stack (-12, +7, +12 st or the held chord's intervals), pitch-synchronous grain, micro-delays, pans |
| 10 | Walkie | `voice.c` | A handset: 350 Hz-3 kHz 4th-order band + a broad presence peak, a mic compressor (every phrase slammed to the same level), asymmetric diode clip, receiver squelch (burst on open, long tail on close), channel muted between phrases with a faint hiss floor while open |
| 11 | Morph | PSOLA lead (`modes.c`) | Formant-decoupled shift into drive (kept; after the roster) |
| 12 | Double | 3 PSOLA voices (`modes.c`) | Hard-tuned lead + two detuned Haas doubles (15-25 ms) (kept; after the roster) |

The order is the Mode knob's: vocoder/carrier modes (0-5), voice transformers (6-10), then Morph and Double. It is `vt_mode` in `dsp.h`, `k_mode_opts` in `dsp.c`, `MODES` in the generator, `MODES` in `canvas.js` (and the tests' tables). **Indices changed in v1.0** (Robot 0, Snap 1: the old Snap 0 / Robot 1 order is gone); saved states name modes, so they load.

All pitch modes (everything except Dalek, Walkie and the vocoders) share one tracker (`cher.c`: MPM + quantizer + delay line). Dalek and Walkie run no tracker (they `cher_listen`); Harmony runs it only to set its grain length.

Talkbox (the old mode 6) was removed on 2026-10-09, and **Nightcall (2026-10-11) is a new, unrelated engine** (a flagged voicing of the vocoder, not the old formant-filter talkbox). A saved `state` with `"mode":"Talkbox"` loads as the default mode (unknown option rejected, the other keys still restored); a numeric index clamps to the last mode (Double).

## Layout

| Path | Role |
|---|---|
| `module.json`, `src/dsp/module_meta.h` | Both generated by `scripts/gen_module_json.py` from one table (the header holds chain_params, as one string per parameter because a pedantic C compiler caps a literal at 4095 characters, and ui_hierarchy as JSON the DSP serves; its chain_params has `@1@`..`@5@` name placeholders for the per-mode macro names). `capabilities` holds `chain_params` (30 params with `default`, then 3 read-only readouts) and `ui_hierarchy`: `modes` `[vocoder, voicefx]` with `mode_param` `engine`, levels `vocoder` (the old root: VOICE / PITCH / MORE links) + `VOICE` + `PITCH` + `MORE`, and `voicefx` |
| `src/dsp/dsp.h` | Host-independent engine API (`dsp_init/process_block/set_param/get_param/handle_midi/cleanup`), param ids, mode ids and the roster / macro map, `vt_param_acts`, `TINYVOICE_OUTPUT_HEADROOM` |
| `src/dsp/dsp.c` | Param table, per-mode macro names (`k_macro_names`) and the char4/char5 aliases (`k_slot_alias`), MIDI voices, mode dispatch, dry-path delay, Tone, Spread chorus, the -6.1 dBFS headroom stage of the new modes, output soft limit, `state`, viz feed, `is_loading` pulse |
| `src/dsp/cher.[ch]` | Tracker: MPM (analysis-path HP + gain), quantizer, auto gate, delay line, lead retune/glide (`cher_lead_lr`), delay-line tap (`cher_tap`), scale steps |
| `src/dsp/psola.[ch]` | TD-PSOLA voice: pitch ratio and formant ratio independent, reads the tracker's delay line |
| `src/dsp/modes.[ch]` | Snap, Morph, Prism (+ glass), Double, Tape, Scream, HardTune on one shared `fx_t` (PSOLA voices, Haas lines, filters) |
| `src/dsp/vfx.[ch]`, `src/dsp/presets.[ch]`, `src/dsp/groove.[ch]` | **Voice FX**, the second personality (section below): the formant engine, its factory bank, and the audition groove Demo plays there |
| `src/dsp/verb.[ch]` | A 4-line FDN tail (2 allpass diffusers, Hadamard mix, in-loop damping). It is **not** a user-facing reverb (Delay / Reverb / Feedback were removed 2026-10-11): it only carries Voice FX's Release |
| `src/dsp/voice.[ch]` | Dalek, Harmony, Walkie on one `vox_t`: no tracker, the input in, stereo out (`vox_set_*` per block, `vox_process`, `vox_latency`, `vox_listen`) |
| `src/dsp/ssb.h` | Header-only 4th-order IIR Hilbert pair (Niemitalo coefficients) and a rotating phasor: Dalek's shifter and Prism's glass |
| `src/dsp/imogen.[ch]` | Chords (harmonizer) and what Prism shares with it: chord voicings (`vt_chord`), the register fit (`vt_fit_register`), the unvoiced high-pass, `VT_HARMONY_TRIM` |
| `src/dsp/daft.[ch]` | Robot and Nightcall: carrier synth + drone, filterbank, AGC, adaptive sibilance, gates; `daft_set_talker` adds Nightcall's pulse width, rasp, EQ, bleed and quieter leveller (all behind `talker`, 0 for Robot) |
| `src/dsp/freeze.[ch]` | Freeze: 16 s int16 looper, Rec and Loop as separate controls, double-buffered (a take never touches the kept loop until it is accepted), exact take length, 5 ms wrap crossfade |
| `src/dsp/demo.[ch]` | Demo voice: real-time formant synth of a 2 s off-pitch sung phrase (every mode, Snap included), held at Auto's working level, and the demo chord progression |
| `src/dsp/vt_floor.h` | Minimum-statistics noise floor for the Auto gates |
| `src/dsp/plugin.c` | Only file that touches the Schwung ABI; thin adapter onto `dsp.h` |
| `src/host/` | Schwung headers, **fetched** by `scripts/fetch_host_headers.sh` (not hand-edited) |
| `src/ui/canvas.js` | OLED widget (`custom:tinyvoice_scope`) drawn by Schwung's param pages across PITCH knobs 5-7; tested by `tests/canvas_test.mjs` (node) |
| `src/dsp/hm.[ch]`, `src/dsp/hm_params.h` | **Resynth**, the third personality (section below): harmonic analysis / resynthesis modelled on Humanoid. `hm_params.h` is the ONE parameter list (X-macro): hm.h's enum, hm.c's table, dsp.c's `hm_*` params and the generator all come from it |
| `src/dsp/mangle.[ch]` | **Mangler**, the fourth personality (`docs/mangler.md`): a multi-voice Granular / Formant (PSOLA) / Vocode pitch shifter modelled on PitchMonster; params `mg_*`, chord slots the `mg_chords` state text, presets `src/presets/Mg - *.json` (ours) and your own imports (`scripts/import_pitchmonster.py`: never commit those) |
| `src/dsp/rsbank.[ch]` | The preset banks (Resynth's, and Mangler's through `rsbank_load_engine`): Resynth's preset bank: the Resynth presets in Schwung's preset folder, read off the audio thread (`plugin.c`'s loader thread), for the Presets page |
| `src/dsp/hmfx.[ch]`, `src/dsp/fft.[ch]` | Resynth's output effects (De-ess, Glitch freeze, Widen) and the radix-2 FFT it runs on |
| `src/ui/web_ui.html` | The Remote UI panel (`move.local:7700/remote-ui`, `schwungRemote` API, keys from `schwungRemote.component`), one set of panels per engine, switched by header tabs (the `engine` param): **Vocoder** (Voice: mode chips + the five per-mode knobs, named from a `MACROS` table that mirrors `k_macro_names`; Pitch; Space / Gate / Freeze; knobs that do nothing in a mode are greyed from an `ACTS` table that mirrors `vt_param_acts`), **Voice FX** (a formant picture, Vowel / Tract / Peak / Choir, Character; preset strip on `vf_preset`), **Mangler** (Shift, Voices, Notes with eight chord fields, Filter / Output; `MG_ACTS` dims what does nothing), **Resynth** (Humanoid's panels, the wave and filter drawn, a piano for the scale mask, Hold Scale / pads, Bank switch and preset strip, Import .baby parsed in the browser, wavetable included). Floats are SVG dials (long enum lists such as Gate too), Off/On are switches, short lists segmented buttons, 6-14 options chips; a key with controls on several panels (Latch, Demo) is merged by `reg()` |
| *(outside the repo)* `C:/Github/TinyVoice-lab` | The Humanoid A/B workbench, **kept out of this repo on purpose (keep it lean)**: `calibration/` (Python, own `.venv`; `hum_host.py` renders the real plugin, `tv_host.py` ours, `ab_*.py` / `probe_*.py` measure, `FINDINGS.md` is every measured law, `make_default_bank.py` writes `src/presets/*.json`), `tools/` (`hm_render.c`, `tv_state_render.c`), `build_tools.sh`, `docs/humanoid-plan.md`. Its own local git; it reads this repo's `src/dsp` (`TINYVOICE` env, default `C:/Github/TinyVoice`). Don't add calibration scripts here |
| `tests/test_main.c` | Single-file test runner with allocation counting; `#include`s `tests/voice_tests.inc` (the v1.0 roster, glass, slots, headroom, numeric safety over every mode) just before `main` |
| `tests/canvas_test.mjs` | Runs `canvas.js` against a mock frame (needle, bars, freeze playhead and recording bar, bounds, junk input) |
| `src/help.json`, `tests/help_test.mjs` | On-device help for the host's Help viewer (and the "Module Help" row on the Module page): Overview, Setup, Vocoder (Pages, Modes, Pads and Latch, Freeze, Gate, Demo), Voice FX (Knobs, Presets, Audition). Top-level `children` is mandatory (anything else is silently discarded), ASCII only, and a line is drawn unwrapped on a 128 px screen: the test enforces structure, ASCII and <= 21 characters, but the real budget is pixels, so after editing run Schwung's measurement (`tests/host/test_help_content_width.sh` derives glyph widths from `scripts/generate_font.py`; v1.0.1 was measured at a widest x=124 of 127). `build.sh` copies it into the package |
| `tests/device_smoke.c` | On-device loader harness (dlopen, dlsym, every callback, all 13 modes timed), run by `scripts/smoke_on_device.sh` |
| `scripts/`, `Makefile` | `build.sh`, `install.sh`, `test.sh`, `smoke_on_device.sh`, `fetch_host_headers.sh`, `gen_module_json.py`; the Makefile (`make test`, `make arm`, `make install`, `make json`) only calls them |
| `scripts/import_humanoid.py`, `scripts/deploy_humanoid_presets.sh` | Convert the user's own Humanoid presets (`C:/ProgramData/BABY Audio/presets/Humanoid`) into Schwung User Presets (`build/humanoid_presets/*.json`, one flat folder: My Presets lists no subfolders), and install them in `/data/UserData/schwung/presets/tinyvoice/`. **Never commit or ship them** (Baby Audio's and their designers' work; `.gitignore` covers `*.baby`, the installer and the manual) |

Everything under `src/dsp/` except `plugin.c` must stay free of Schwung includes so tests can link it natively.
